Double Check — all-formats fixture

Focus any field and press the shortcut (Shift+Command+Space on a Mac — shown by Chrome as ⇧⌘Space — or Ctrl+Shift+Space elsewhere). Pre-filled fields open in verify mode; empty ones in input mode. Each field lists a valid sample to type and an invalid one to see the red diagnosis. For screen-region scanning, serve this page over http (python3 -m http.server in the repo root, then localhost:8000/tests/pages/all-formats.html) — or enable “Allow access to file URLs” for the extension if you open it as a file. To exercise Submit Guard: add this page’s origin in Settings, verify a field, then try Send.

Masked fields (type=password)

Sites mask high-stakes values (a "re-enter account number" or a PIN). Double Check should treat these as sensitive: the match screen stays masked behind a Reveal toggle, the re-type box is masked too, and read-aloud is disabled — so nothing the site hid is shown in our card either.

prefilled + masked → verify mode; match screen masks the value behind Reveal, re-type box shows dots
empty + masked → two-step input mode; both entries stay masked
value reads as all X’s; real digits live in the hidden identitySsnx field → Double Check switches to double-entry, and "Show value" recovers the real value from the hidden field
